# Лабораторна робота №3

Рекурентна фільтрація та адаптивне оцінювання місячної кількості відгуків Cyberpunk 2077 у Steam.

## Запуск

Потрібні Python 3.12 або новіший, Git та uv. Залежності зафіксовані в `uv.lock`.

Завантаження та повний запуск (Windows, macOS або Linux):

```shell
git clone https://github.com/Artychanal/time-series-lab-3-serkeli.git
cd time-series-lab-3-serkeli
uv sync --frozen
uv run --frozen python -B -X utf8 main.py
```

Якщо uv ще не встановлено:

```shell
python -m pip install uv
```

Для швидкого ознайомлення можна виконати `uv run --frozen python -B -X utf8 main.py --simulations 30 --output results_quick`. Такий запуск зберігає результати в окремій папці. Повний запуск використовує 300 реалізацій на сценарій.

У PyCharm виберіть інтерпретатор `.venv/Scripts/python.exe` і запускайте `main.py`. Вхідні дані та стандартна папка результатів визначаються від розташування скрипта. Мережа для обчислень не потрібна.

За замовчуванням програма виконує по 300 незалежних реалізацій шести синтетичних сценаріїв із seed 42. Доступні параметри `--data`, `--output`, `--simulations` (щонайменше 30) і `--seed`.

## Функціональність

- Перевірка місячних даних, сум, часток і походження джерела.
- Причинне виявлення аномалій та компенсація контрольованих помилок.
- Фільтри α–β, α–β–γ та модель рівня; сталі й рекурентні підсилення.
- Оцінювання Q/R максимальною правдоподібністю.
- Адаптація Q, вибір пам’яті та контроль NIS.
- Хронологічна валідація та окрема фінальна перевірка прогнозів.
- Синтетичне дослідження похибки справжнього стану, зміщення та покриття інтервалів.
- Прогноз на три місяці, таблиці CSV, підсумки JSON і 10 графіків PNG.

## Дані та оцінювання

Використовуються 69 повних місяців від грудня 2020 до серпня 2026. Вересень у збереженому знімку неповний і виключений. Аналіз виконується в шкалі `log(1 + кількість відгуків)`.

Перші 24 місяці використовуються для початкового оцінювання параметрів, наступні 33 — для валідації, останні 12 — для фінальної перевірки. Прогноз оцінюється до врахування поточного вимірювання. Майбутні спостереження недоступні алгоритму.

Статистично незвичні реальні сплески зберігаються. Компенсація оцінюється на синтетичних помилках із відомими правильними значеннями. В адаптивних моделях R залишається фіксованим; наслідки цього обмеження показані окремим сценарієм зростання шуму вимірювання.

На реальному ряді серед α–β та α–β–γ обрано α–β. Адаптивна модифікація допомагає при синтетичній зміні рівня, але погіршує прогноз на реальній фінальній ділянці. Після запуску повні числові результати зберігаються в `results/analysis_summary.json`.

## Структура

```text
time-series-3/
├── main.py
├── analysis.py
├── data_loader.py
├── kalman_filters.py
├── parameter_estimation.py
├── adaptive_filter.py
├── anomaly_detection.py
├── synthetic_data.py
├── evaluation.py
├── visualization.py
├── data/
├── pyproject.toml
├── uv.lock
└── README.md
```

`main.py` запускає дослідження; `analysis.py` керує його етапами. Решта модулів відповідають за підготовку даних, фільтри, оцінювання параметрів, адаптацію, аномалії, синтетичні сценарії, статистичне оцінювання та графіки.

Основні результати: `validation_comparison.csv`, `test_model_comparison.csv`, `innovation_diagnostics.json`, `adaptation_history.json`, `monte_carlo_summary.csv`, `forecast_3_months.csv` та графіки в `results/figures`. Слово `test` у назвах файлів результатів означає фінальну хронологічну вибірку.

Папка `results/` із таблицями, підсумками та графіками створюється автоматично під час запуску.
